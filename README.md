# Gerenciador de Gastos Mensais 💰

Este é um script simples em Python desenvolvido para ajudar no controle financeiro pessoal, permitindo o registro de receitas e despesas com a exibição do saldo final.

## 🚀 Funcionalidades
* Registrar o total de receitas (ganhos).
* Adicionar múltiplas despesas com descrição e valor.
* Calcular e exibir o saldo final atualizado.

## 🛠️ Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina:
* **Python 3.x**

## 💻 Como Executar o Projeto

1. Abra o terminal ou prompt de comando (CMD) na pasta do projeto.
2. Execute o script com o seguinte comando:
   ```bash
   python script.py
   ```

## 📝 Exemplo de Uso
Ao rodar o código, o terminal solicitará as entradas:
```text
--- GERENCIADOR DE GASTOS MENSAL ---
Digite o valor total das suas receitas (R\$): 3000.00

Digite a descrição da despesa (ou 'sair' para finalizar): Aluguel
Digite o valor de 'Aluguel' (R\$): 1200.00

Digite a descrição da despesa (ou 'sair' para finalizar): Internet
Digite o valor de 'Internet' (R\$): 100.00

Digite a descrição da despesa (ou 'sair' para finalizar): sair

--- RESUMO FINANCEIRO ---
Total de Receitas: R\$ 3000.00
Total de Despesas: R\$ 1300.00
Saldo Final: R\$ 1700.00 (Saldo Positivo)
```
